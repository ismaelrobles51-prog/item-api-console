# Offline layout library

These presentation-only pages were transferred from the local `TMS-Proxy - Anlytics Update` workspace.

Included current layouts:

- `tms-agent/` — main FR8 Dispatch shell
- `analytics-ytd/` — year-to-date analytics dashboard
- `dispatch/` — dispatch and Local P&D workspace
- `module-breakdown/` — dispatch lifecycle reference pages

The import intentionally excludes environment files, credentials, proxy/server code, API clients, authentication logic, live data, logs, dependencies, and historical backup files. Original scripts, external resources, and inline event handlers were removed from the copied HTML; the TMS Agent copy includes only local panel navigation and theme switching.

Open `layouts/index.html` to browse the collection. The repository root `index.html` remains the deployed TMS Agent layout.
