Module purpose

Orders

Present the shipment population, its current operational state, and the subset eligible for routing and linehaul planning.

Upstream data→Orders→Downstream handoff

Inputs / Data

  • PRO/order ID and pickup number
  • Origin/current terminal and default terminal
  • Consignee city, state and ZIP
  • Stage, MABD, pallets, weight and revenue
  • Current trip assignment and routing-plan match

Core workflow

Fetch outbound/open order data by terminal
Normalize numeric stage codes into business labels
Filter by stage, origin, routed destination, exceptions or search
Open a detail panel for summary, route, freight and history
Pass eligible unassigned freight into active-lane grouping

Key business logic

  • Stage codes map to Pickup, Pickup Complete, Linehaul, Linehaul Complete, Out-for-Delivery and Delivery Complete
  • Planning eligibility includes Pickup, Pickup Complete and Linehaul Complete
  • CO, MT and WY remain manual-route exceptions unless a matrix rule resolves them
  • An uploaded routing plan may override inferred lane buckets for a PRO

Outputs / Next step

  • Eligible order set to Routing Guide and Linehaul Manager
  • Order detail and exception records to operators and analytics

KPIs

  • Total and eligible orders
  • Inbound / outbound volume
  • Orders by stage
  • Order dwell and aging
  • MABD urgent count

Alerts / Exceptions

  • Missing current terminal
  • Unrouted exception state
  • MABD within three days
  • Duplicate or existing trip assignment
