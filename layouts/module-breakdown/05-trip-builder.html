Module purpose

Trip Builder

Turn lane-qualified orders into one or more executable linehaul load plans.

Upstream data→Trip Builder→Downstream handoff

Inputs / Data

  • Orders grouped by active lane
  • Order weight and pallet totals
  • MABD/service priority
  • Existing trip capacity
  • Configured maxLbs and maxPlts settings

Core workflow

Open the selected lane
Sequence and select eligible orders
Accumulate weight and pallet totals
Split freight into additional trip candidates when capacity logic requires
Stage the resulting trip manifest for creation

Key business logic

  • Default displayed capacity: 40,000 lb and 54 pallets
  • Current code comments state trailer splitting is weight-only
  • Pallet count currently renders fill percentage but does not independently force a split
  • Target rule from the workflow requirement is split when either 40,000 lb or 54 pallets would be exceeded

Outputs / Next step

  • Capacity-reviewed trip candidate to Pre-Planned Trip Creation

KPIs

  • Weight utilization
  • Pallet utilization
  • Orders per trip
  • Unused capacity
  • Split-trip count

Alerts / Exceptions

  • Over 40,000 lb
  • Over 54 pallets
  • Low utilization
  • Order cannot fit without a split

As-built vs intended rule

Implementation gap: align the current weight-only splitter with the intended OR rule so either weight or pallets creates a new trip.
